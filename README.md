This project analyzes flight price data to understand how factors such as airline, route, number of stops, departure timing, booking date, and travel class affect airfare prices. After cleaning and preprocessing the datasets, exploratory data analysis was performed to identify important trends. The analysis showed that airlines like Vistara and Air India have higher average fares, while AirAsia and Indigo are more affordable. It was also observed that ticket prices increase significantly when flights are booked closer to the departure date. Additionally, business-class flights were found to be much more expensive than economy-class flights, highlighting the strong impact of travel class on pricing.
